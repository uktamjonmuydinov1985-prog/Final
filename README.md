# Kino Bot

Telegram kino bot for FadeHost.

## Admin commands

- `/save KOD | Kino nomi` — then send the video
- `/list`
- `/delete KOD`
- `/addchannel @kanal`
- `/delchannel @kanal`
- `/channels`

Default mandatory channel: `@kino_tarjimaa_uzz`

The bot token is temporarily embedded in `index.js` as requested. Rotate the token with BotFather after deployment.
